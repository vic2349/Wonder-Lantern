# 自定义快门声 · 声音规范

适用：Nikon Z6 C3.80自定义快门声驻留v3。更新：2026-10-07。

## 必须满足的格式

| 项目 | 要求 |
|---|---|
| 文件容器 | RIFF/WAVE、小端 |
| 编码 | 非压缩有符号16位整数PCM，format tag=1 |
| 采样率 | 8000Hz |
| 声道 | 单声道 |
| 字节率 / 块对齐 | 16000 bytes/s / 2 bytes |
| 文件头 | 标准44字节头，fmt长度16，data紧随其后 |
| PCM数据长度 | 非空、偶数，最多17280字节，即8640采样点 |
| 最大时长 | 1.08秒，包括淡入、淡出与静音 |
| 最大文件大小 | 17324字节 |

RIFF和data声明长度须与实际文件一致。不能包含LIST、JUNK、bext、封面等额外块。MP3、浮点WAV、双声道和44.1/48kHz文件须先转换，不能只改扩展名。固件不会自动截短超长文件；WAV加载失败保留上一种可用声音。

## 卡上命名

| 菜单选择 | 路径 |
|---|---|
| 卡上默认 | /SHUTTER.WAV |
| 1 | /SHUTTER/1.WAV |
| 2 | /SHUTTER/2.WAV |
| 3 | /SHUTTER/3.WAV |
| 4 | /SHUTTER/4.WAV |

使用1.WAV，不用01.WAV；建议上述大写ASCII命名。菜单固定显示编号，不读取自定义名称。增加5.WAV不会增加菜单选项，MEOW.WAV等旧名不作为本版编号槽读取。

SHCORE.BIN是必需的配套核心，保留卡根；SHUTTER.SEL是相机生成的配置，保存编号与On/Off，正常保存后重启恢复。不手动修改配置文件。

## 声音制作建议

- 连拍优先：0.10～0.20秒，辨识点尽量放在前50ms。
- 短提示：0.20～0.50秒；完整音效：0.50～1.08秒。
- 去掉前导静音，目标不超过5ms；头部淡入约1～3ms，尾部淡出约5～10ms。
- 建议峰值不超过−0.5dBFS，避免削顶。不同声音有效段RMS可从约−8dBFS起调，以峰值及机身试听为准；这些都是制作建议，固件不会自动归一化。

每张照片重新播放并截断上一声，不排队、不叠加。长音在连拍时只能听到开头属于预期行为，1.08秒是格式硬上限。

## 最短定制流程

1. 保留原录音，另裁取成品并去掉前导静音。
2. 在音频编辑器转为单声道、8000Hz、PCM16，处理首尾和响度。
3. 导出无附加元数据的标准44字节头WAV，检查长度与大小。
4. 将文件命名为目标槽编号，复制到卡上。
5. 相机选择该编号或“重新载入”，等读写完成后用“播放”确认，再测试短曝光单拍及连拍。

首发包示例全部为0.20秒合成测试音，可直接替换。
