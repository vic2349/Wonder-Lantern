# Nikon Z6 自定义快门声

版本：2026-10-08。适用机型仅为Nikon Z6，基于C3.80；

提供独立中文或英文快门声菜单、卡载换声、四个编号槽、试听和重新载入，声音编号与开关保存在卡上。连拍时每张从头播放，截断上一声。慢门开/关双音效未实现。

## 包内文件
z6/costom shutter sound自定义快门声/
- cn/SHCORE.BIN：中文菜单核心，与根目录EG162080.BIN配套。
- en/：英文配套EG162080.BIN与SHCORE.BIN。
- EG162080.BIN：中文主固件
- SHUTTER.WAV：卡上默认示例。
- SHUTTER/1.WAV～4.WAV：四个声音示例：1猫声、2 某胶片相机快门声、3鸟声、4 某苏相机镜间快门声。
- 声音要求.md：声音格式、命名与制作规范。


## 安装与使用

1. 备份卡上原有设置相关文件，*建议移走照片以后复制整个卡根下的文件进行备份*。
2. 中文将根目录EG162080.BIN与cn/SHCORE.BIN复制到卡根，英文将en/内两份BIN复制到卡根；声音示例为根目录SHUTTER.WAV和SHUTTER文件夹，也复制到卡根；相机中从“固件版本”执行更新，更新期间不要断电。按Nikon固件更新要求使用充足电量。
3. 更新完成后关机重开。启动等约5秒、读写指示灯熄灭后，进入设置菜单中的快门声音，选择开启、编号或播放。
4. 更换音效只需替换对应WAV，选该编号或使用“重新载入”，无需再次刷固件。
5. *特别注意*：新添加的菜单只能使用方向键，触屏与ok键均不可使用


## 使用说明

首先你需要更新固件，如果你完全按照了安装与使用做了，那么你可以先探索一下这个功能，自定义快门声相关设置在设定菜单的固件版本下方，*开机后的快门声是被截断的猫叫，是正常情况*，体验完以后你可以关机拔卡然后根据声音要求.md中的要求替换1234为你自己想要的快门声，不要放多了，可以少但是不要多


## 停用与恢复

菜单关闭只停用拍摄时的自定义声音。关机后移走SHCORE.BIN再开机，会进入缺核心回退路径。
要恢复整份原厂固件，使用Nikon官方Z6固件并按官方更新流程操作。
